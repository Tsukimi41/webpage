> これはアニメーションを含む記事画面の見え方を確かめるための架空記事です。

## 動きに役割を持たせる

アニメーションは装飾として一律に足すのではなく、次のどれを担当するか決めます。

- 情報の階層を伝える
- 操作への反応を返す
- サイトらしい楽しさを作る

役割を説明できない動きは、読み進める負担を増やさないよう追加しません。

## 動きを減らす設定

`prefers-reduced-motion` が有効な場合は、大きな移動や繰り返しを止めます。内容や操作はアニメーションの有無に依存させません。

```css
@media (prefers-reduced-motion: reduce) {
  .decorative-motion {
    animation: none;
    transition: none;
  }
}
```

### 停止後にも残すもの

フォーカス枠、選択状態、見出し階層は動きではなく、静的な形や文字でも伝わるようにします。

## 確認の観点

キーボード、タッチ、マウスの順に操作を分けず、どの入力でも同じ内容へ到達できるかを確認します。200%拡大時には文字の重なりだけでなく、横スクロールの発生範囲も見ます。
