## 調べる前に現在地を見る

変更を始める前に、作業中のブランチと差分を確認します。

```powershell
git status --short --branch
git diff --check
```

コマンドだけでなく「何を確かめるためか」も一緒に残すと、時間が経ってから見返しやすくなります。

## 結果も残す

成功したコマンドだけではなく、対象件数、未確認の環境、次に人が見る箇所も記録します。短いメモでも判断の背景が残れば、次の作業へ安全につなげられます。
