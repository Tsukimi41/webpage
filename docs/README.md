# 個人ポートフォリオサイト 設計ドキュメント

最終更新: 2026-09-14

このディレクトリは、個人ポートフォリオ兼技術ブログの企画・設計判断を記録する。
会話で合意した事項と、今後決める事項を混同しないよう、各項目を次の状態で管理する。

- **決定**: ユーザーとの会話で合意済み
- **暫定**: 現時点の推奨案。比較・検証後に変更できる
- **未決定**: 実装前に追加情報または判断が必要

## 文書一覧

- [product-requirements.md](./product-requirements.md): 目的、対象者、要求、機能要件、非機能要件、公開範囲、完成条件
- [design-system.md](./design-system.md): 参考サイト、視覚方針、書体、色、アニメーション、レスポンシブ、アクセシビリティ
- [architecture-and-operations.md](./architecture-and-operations.md): 技術選定、費用方針、公開・更新・保守方法、判断記録
- [development-workflow.md](./development-workflow.md): 小さな実装単位、確認、コミット、変更管理の進め方

## 現在地

要件定義・基本設計の途中。サイト本体の実装はまだ開始しない。

### 決定済みの要点

- 就職活動を主用途とする、ポートフォリオ兼技術ブログにする
- 企業の採用担当者・現場エンジニア、大学の友人、イベントで知り合った人、技術系の読者を対象にする
- 名前はペンネームまたはハンドルネームを使用する
- 大学名、学部・学科、連絡用メールアドレスを公開する
- 技術力、制作物、活動履歴、日々の備忘録、技術記事を掲載する
- 年別タイムラインを設ける
- 明るくポップで、現代的かつ整然としたデザインにする
- CSSアニメーションを中心に、見ていて楽しい仕掛けを入れる
- 無料フォントを使用し、技術感と親しみやすさを両立する
- Safari、Chrome、Edge、Firefox、およびiPhone、Android、PCで同等の情報・操作体験を提供する
- 初期費用・継続費用をできるだけ抑える
- 機能を小さなステップに分け、各ステップで意図を確認してからコミットする

### 次に決めること

1. ハンドルネーム、大学・学部・学科の正式表記、公開用メールアドレス
2. 代表プロジェクト3件と、それぞれの担当範囲・成果・使用技術
3. 年表に載せる出来事
4. ブログの初期カテゴリと初回公開時の記事数
5. 最終的な書体、配色、サイト固有のモチーフ
6. 独自ドメインの有無と公開先
